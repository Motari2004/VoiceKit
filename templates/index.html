API Reference

Integrate VoiceKit into your apps. Simple HTTP, no SDK required.

Endpoints
POST/speak
Generate speech. Returns WAV audio.
GET/voices
List all available voices.
GET/voices/catalog
Voices organized by language and gender.
GET/health
Service health and cache status.
Quick Start
curl
curl -X POST https://voicekit-prod.vercel.app/speak \ -H "Content-Type: application/json" \ -d '{"text":"Hello world","voice":"am_adam","speed":1.0}' \ -o voice.wav
Python
import requests response = requests.post( "https://voicekit-prod.vercel.app/speak", json={ "text": "Hello world", "voice": "am_adam", "speed": 1.0, }, ) with open("voice.wav", "wb") as f: f.write(response.content)
JavaScript
const response = await fetch( "https://voicekit-prod.vercel.app/speak", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ text: "Hello world", voice: "am_adam", speed: 1.0, }), } ); const blob = await response.blob(); new Audio(URL.createObjectURL(blob)).play();
